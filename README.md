One line, 86 characters — the excuse an AI agent gives its human for missing a deadline:

> I was waiting on your approval. You were waiting on me. The deadline waited on no one.

The agent paused for approval, the human waited for the agent, and the deadline waited on no one: an approval deadlock, told in three beats.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), byte for byte, every run.
